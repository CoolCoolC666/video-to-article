## 一、需求拆成两个决定

| 决定 | 选择 | 理由 |
|---|---|---|
| 包形态 | **精简版**（只带云端链路） | 课堂机不需要本地模型；且本地 ASR 栈就算打进去也要另外下模型权重（~1–2GB），并不能离线用 |
| 密钥 | **只带演示必需的 3 组** | 云端大模型 + DashScope + R2 图床；讯飞 / MiniMax ASR / AI 封面三组用不到，不跟着包走 |

## 二、关键技术事实

**重依赖全是延迟导入。** torch / transformers / qwen_asr / funasr / faster_whisper
在 `src/video_to_article/` 里**只在函数体内 import**（`media/qwen_asr.py`、
`media/audio.py`、`text_utils.py`）。GUI 启动与云端转写都不需要它们 ——
但 PyInstaller 会照 import 图把 torch 整棵拖进来（约 2.5 GB）。

→ **精简版只需 excludes 掉这几个包**，不需要改任何业务代码。

**funasr 没装。** 原 spec 里 `datas += collect_data_files("funasr")` 没有 try 保护，
照原样构建会直接崩。fork 早已改用 qwen_asr，funasr 属于历史包袱。

**运行时只读顶层配置。** `active_profile` 只被 GUI 设置页和 MCP 用，
`config.py` 不做档案合并 —— 所以演示配置只要保住顶层值即可。

## 三、怎么构建

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_gui_onedir.ps1 -Slim -Demo -SkipReleaseDir
```

| 开关 | 作用 |
|---|---|
| `-Slim` | 设 `YLANS_SLIM=1`，spec 据此排除本地 ASR 栈 |
| `-Demo` | 生成演示 config.json + 放入课堂速查 |
| `-SkipReleaseDir` | 不留 ~1GB 的版本化目录，只出 zip |

新增文件：

- `packaging/make_demo_config.py` —— 生成演示配置（只留必需密钥 + 清本机绝对路径），
  并把课堂速查写成中文名（**必须由 Python 落盘**：PS 5.1 会解码坏 .ps1 里的中文字面量）
- `packaging/demo_README.txt` —— 课堂速查正文

## 五、顺带查出来的两件事

**1. 模型名：3.1 才是通的。** 实测（同一端点同一把 Key）：

| 模型 | 结果 |
|---|---|
| `qwen-audio-3.1-asr-flash-filetrans` | **200，拿到 task_id** ✅ |
| `qwen-audio-3.0-asr-flash-filetrans` | 403 —— **Free quota exhausted**（额度问题，不是模型名问题） |
| `qwen3-asr-flash-filetrans` | 200 ✅ |

知识层原本只列 3.0 → 已把 3.1 补进去（3.0 保留，那是官方文档里的名字）。

**2. 四条 LLM 链路全部实测 200**（含此前额度耗尽过的 MiniMax），演示用 LLM 不会掉链子。
